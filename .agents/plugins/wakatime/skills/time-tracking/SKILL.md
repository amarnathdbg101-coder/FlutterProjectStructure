# WakaTime Productivity Tracker Skill

## 1. Feature Velocity Tracking
- Logs task start and completion timestamps to correlate productivity with sprint milestones.
- Groups code review, refactoring, and feature builds into clear intervals.

## 2. Editor Extension Integration
- Integrates with the official WakaTime VS Code extension (`WakaTime.vscode-wakatime`) using your personal API key stored in `~/.wakatime.cfg`.
